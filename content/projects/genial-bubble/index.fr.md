## À propos du projet

Genial Bubble est notre jeu pour la Global Game Jam 2025, dont le thème était « Bubble ». Votre seule arme : des bulles. Lancez-les pour emprisonner les araignées et les bonhommes de neige qui vous barrent la route, ou servez-vous-en pour rebondir et actionner les mécanismes qui vous permettront de franchir les niveaux.

Il existe deux sortes de bulles :

- la **bulle offensive** emprisonne les ennemis qu'elle touche ;
- la **bulle de résolution** s'immobilise là où elle tombe : on peut rebondir dessus ou la loger dans un bouton pour déclencher un mécanisme. Une seule à la fois, choisissez bien où la lancer !

## Fonctionnalités

- Gameplay rétro inspiré des jeux d'arcade.
- Développé en 48 heures chrono avec Unity.
- Jouable directement dans le navigateur.
- Codé avec amour par l'équipe de choc.

## Commandes

Les touches ci-dessous sont celles d'un clavier AZERTY ; sur un clavier QWERTY, utilisez A et W à la place de Q et Z.

| Action | Touche |
| --- | --- |
| Se déplacer | Q / D |
| Sauter | Espace ou Z |
| S'accroupir | S |
| Lancer une bulle offensive | J |
| Lancer une bulle de résolution | H |
