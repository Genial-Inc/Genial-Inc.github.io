## About the project

**Genial Bubble** is a 2D platform game that combines platforming with puzzles built around the concept of bubbles. The team created it for the [2025 Global Game Jam](https://globalgamejam.org/).

## Source code

The game was developed with Unity. Its public repository is available on [GitHub](https://github.com/Genial-Inc/Genial-Bubble).
