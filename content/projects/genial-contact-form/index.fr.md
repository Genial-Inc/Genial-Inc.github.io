## À propos du projet

Remplir un formulaire de contact, c'est trop facile. Pour la Nuit de l'Info 2025, nous avons donc imaginé le formulaire de contact le plus pénible possible.

Le prénom, le téléphone et le message se remplissent normalement… mais pas le courriel. Pour l'écrire, il faut choisir chaque caractère sur une roulette, le placer dans un lance-pierre et le **tirer** dans le bon champ. Et ce n'est pas tout :

- les champs **changent de place** toutes les dix secondes ;
- la touche reste immobile une seconde après chaque tir ;
- en cas d'erreur, une **bombe** permet d'effacer ce qui a été écrit ;
- chaque tir est accompagné d'un son, réussi ou raté (activez le son, mais pas trop fort) ;
- un chronomètre mesure le temps passé sur la page, que l'on découvre au moment d'envoyer le formulaire.

Bonne nouvelle : rien n'est réellement envoyé.

## Essayer

Le formulaire est jouable directement sur ce site. Il est en français et se joue à la souris.
